# AIS COMPANY — النظام الجديد

هذه النسخة المجمعة تحتوي على كل ما تم اعتماده لنظام AIS منذ تصميم الواجهات وحتى نهاية Phase 11.

## المحتويات

- `src/`: واجهة React/Vite ونظام التصميم.
- `server/`: طبقة الخادم الحالية والتهيئة.
- `prisma/`: Prisma schema وmigrations الخاصة بـ AIS.
- `docs/`: المواصفات والمراجعات ومصفوفات الاختبار.
- ملفات الجذر: إعدادات TypeScript وVite وEnvironment example.

## الحالة الحالية

- Phase 0: مكتملة.
- Phase 1: مكتملة.
- Phase 2: مكتملة، ومخطط AIS مطبق على PostgreSQL.
- Phase 3: مكتملة، محرك العمليات المالية.
- Phase 4: مكتملة، المصادقة والصلاحيات.
- Phase 5: مكتملة، إدارة الجهات.
- Phase 6: مكتملة، الحوالات.
- Phase 7: مكتملة، التسويات.
- Phase 8: مكتملة، الأرصدة والتقارير.
- Phase 9: مكتملة، مزامنة الخادم.
- Phase 10: مكتملة، النسخ الاحتياطي.
- Phase 11: مكتملة، بوابة الاختبارات الشاملة.

## ملاحظات

- لا يحتوي هذا المجلد على `node_modules` أو ملفات مؤقتة أو نسخ EXE القديمة.
- لا يحتوي على كلمات مرور أو بيانات اتصال حقيقية.
- تشغيل `npm run test:all` يشغل جميع اختبارات الوحدات والحدود الحالية.
- جداول AIS في PostgreSQL معزولة بأسماء تبدأ بـ `ais_` لأن قاعدة البيانات كانت تحتوي مسبقاً على جداول قديمة غير متوافقة.
- النسخة الأصلية في جذر المشروع لم تُحذف، وهذه المجلد نسخة تجميعية مستقلة.
