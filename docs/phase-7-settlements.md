# Phase 7 — التسويات

## النطاق المنفذ

تمت إضافة التسويات المرتبطة بالجهة والعملة، مع احتساب أثرها الفعلي على الرصيد الحالي قبل تسجيل العملية.

المسارات:

- `GET /api/settlements` للعرض والبحث.
- `POST /api/settlements` للمدير فقط.
- `GET /api/settlements/:id` للعرض.
- `PATCH /api/settlements/:id` للمدير، مع السماح بتعديل التاريخ والملاحظات فقط.
- `DELETE /api/settlements/:id` للأرشفة المنطقية للمدير.

## القواعد

- `THEY_PAID_US` يستهلك رصيد `WE_ARE_OWED`.
- `WE_PAID_THEM` يستهلك رصيد `THEY_ARE_OWED`.
- التسوية الزائدة تنشئ أثراً معاكساً بالمقدار المتبقي.
- لا تختلط العملات عند حساب الرصيد.
- المبلغ أكبر من صفر، والعملات الخمس فقط.
- الحوالات والتسويات المؤرشفة لا تدخل في الرصيد الحالي.
- إنشاء التسوية وآثارها وسجل التدقيق يتم داخل معاملة PostgreSQL واحدة.
- لا يمكن تغيير الجهة أو العملة أو المبلغ أو اتجاه التسوية بعد تسجيلها، حفاظاً على التاريخ المالي.

لم تبدأ بعد كشوف الحساب أو التقارير أو المزامنة.
