# Phase 5 — إدارة الجهات والأطراف

## النطاق

تم إنشاء طبقة بيانات موحدة للجهات الثلاث المحددة في المواصفات:

- `PERSON`: شخص مع ملف `PersonProfile`.
- `OFFICE`: مكتب مع `ownerName`.
- `COMPANY`: شركة مع `responsibleName`.

البيانات المشتركة محفوظة في `Party`، والحقول المتخصصة في ملف النوع المرتبط. لا توجد جداول منفصلة مكررة لكل نوع.

## قواعد العمل

- الاسم مطلوب ومحدود الطول.
- جميع النصوص تُنظف وتُتحقق على الخادم.
- لا يمكن تغيير نوع الجهة بعد إنشائها.
- الحذف منطقي عبر `isArchived` حتى لا تنكسر روابط الحوالات والتسويات المستقبلية.
- البحث يقتصر على الجهات غير المؤرشفة.
- الإنشاء والتعديل يتمان داخل معاملات PostgreSQL عند الحاجة إلى إنشاء ملف النوع.

## ما لم يُنفذ

لم تبدأ هذه المرحلة الحوالات أو التسويات أو الأرصدة الافتتاحية أو واجهاتها.
