# Phase 6 — الحوالات

## النطاق المنفذ

تمت إضافة طبقة خادمية للحوالات المرسلة والمستلمة، مرتبطة بجدول `Party` ومحمية بصلاحيات Phase 4.

المسارات:

- `GET /api/transfers` للعرض والبحث.
- `POST /api/transfers` للمدير فقط.
- `GET /api/transfers/:id` للعرض.
- `PATCH /api/transfers/:id` للمدير فقط.
- `DELETE /api/transfers/:id` للأرشفة المنطقية للمدير فقط.

## قواعد الحوالة

- العملات المسموحة: USD وIQD وIRR_TOMAN وEUR وSAR.
- الاتجاهان: `SENT` و`RECEIVED`.
- `amount` أكبر من صفر.
- `commission` صفر أو أكبر.
- `total` يحسب خادمياً باستخدام Decimal ويساوي `amount + commission`.
- الحوالة المرسلة تسجل أثراً `WE_ARE_OWED`.
- الحوالة المستلمة تسجل أثراً `THEY_ARE_OWED`.
- الجهة والعملة لا تتغيران بعد إنشاء الحوالة.
- الإنشاء والتعديل والأثر المالي وسجل التدقيق تتم داخل معاملة PostgreSQL.
- الحذف منطقي للحفاظ على التاريخ المالي.

لم تبدأ بعد التسويات أو كشوف الحساب أو الأرقام الموزعة للعمل Offline.
