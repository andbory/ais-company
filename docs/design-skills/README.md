# مراجع إعادة تصميم AIS Company

هذا المجلد يحتوي على نسخة مرجعية محلية من مهارات تصميم الواجهة وتجربة الاستخدام التي تم فحصها من مستودعين مفتوحين المصدر. هذه الملفات مرجع للتصميم والتنفيذ وليست جزءاً من حزمة التشغيل أو منطق PostgreSQL.

## المصادر المفحوصة

- [UI UX Pro Max Skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) — تصميم الأنظمة، الرموز، قابلية الوصول، التصميم المتجاوب، والبحث حسب المجال.
- [Emil Kowalski Skills](https://github.com/emilkowalski/skills) — مبادئ Apple Design، الحركة الهادئة، التفاعل، ومراجعة الرسوم المتحركة.

## الملفات المنقولة

داخل `sources/`:

- `ui-ux-pro-max-design`: قواعد التصميم والبيانات المرجعية للألوان والأنماط والرموز.
- `ui-ux-pro-max-design-system`: بنية Design Tokens بثلاث طبقات: primitive ثم semantic ثم component.
- `ui-ux-pro-max-ui-styling`: إرشادات المكونات، النماذج، الوصول، والـ responsive layout.
- `emil-apple-design`: مبادئ Apple في الاستجابة، الوضوح، التناسق المكاني، المواد الشفافة، الخطوط، وتقليل الحركة.
- `emil-emil-design-eng`: منهجية تنفيذ الحركة والتفاعل.
- `emil-animate`: قواعد اختيار الحركة والأداة والمنحنى والمدة.
- `emil-review-animations`: قائمة مراجعة صارمة للحركة والأداء وقابلية الوصول.
- `emil-improve-animations`: منهج تدقيق الحركة على مستوى المشروع.
- `emil-find-animation-opportunities`: تحديد الأماكن التي تستحق حركة والأماكن التي لا تحتاجها.
- `emil-animation-vocabulary`: قاموس مصطلحات الحركة لاستخدامها بدقة أثناء التصميم.

## الخلاصة المعتمدة للنظام

سيتم بناء إعادة التصميم على:

1. نظام رموز واضح بدل القيم المتناثرة.
2. واجهة عربية RTL أولاً، مع دعم الشاشات الصغيرة واللمس.
3. مظهر Apple هادئ: أسطح شفافة بقدر محدود، حدود دقيقة، وضوح عالٍ، ومساحات مريحة.
4. استخدام الخط النظامي أولاً، مع ضبط الحجم والتباعد والارتفاع البصري للنص.
5. حركة وظيفية قصيرة فقط: feedback، وضوح الحالة، واستمرارية المكان.
6. عدم استخدام `transition: all` أو حركات تؤثر على التخطيط، مع احترام `prefers-reduced-motion`.
7. عدم تحويل هذه المراجع إلى تبعيات تشغيلية أو إضافة مكتبات جديدة قبل الحاجة الفعلية.

## ما لم يتم نقله

تم استبعاد أمثلة المشاريع، ملفات العروض، أصول التسويق، أدوات الشعارات، وخطوط لا يحتاجها النظام حالياً. كما لم يوجد ملف محلي باسم `apple design` داخل المشروع؛ المرجع المستخدم هو `emil-apple-design/SKILL.md` المنقول من مستودع Emil.
