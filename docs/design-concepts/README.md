# نماذج تصميم الفواتير والتقارير

هذه الملفات معاينات تصميمية مستقلة، ولا تغيّر الواجهات الحالية للنظام.

كل لوحة تضم ثلاثة نماذج متجاورة:

1. فاتورة حوالة.
2. كشف حساب.
3. تقرير مالي.

## النماذج

- `model-1-formal.svg`: نموذج رسمي واضح، مناسب للطباعة والمستندات التجارية.
- `model-2-glass.svg`: نموذج داكن بلمسة Liquid Glass هادئة.
- `model-3-print.svg`: نموذج عملي عالي التباين، يركز على القراءة والطباعة.

بعد اختيار نموذج واحد، يمكن تطبيق لغته البصرية على شاشات الفواتير والتقارير والكشوف فقط.
